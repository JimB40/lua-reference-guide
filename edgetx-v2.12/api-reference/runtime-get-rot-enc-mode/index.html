    getRotEncMode

    getRotEncMode()

    Return rotary encoder mode

    Parameters

    None.

    Returns

    Name Type Description
    - integer in list: Normal = 0, Both V and H inverted = 1, V-N = 2, V-A = 3 return 0 on radio without rotary encoder

    Availability

    • Since: 2.8.0
    • Radio support: all
