# lvgl.isAppMode

`lvgl.isAppMode()`

Return whether the current script is running in app mode.

## Parameters

None.

## Returns

| Name | Type | Description |
| --- | --- | --- |
| `-` | `boolean` | true when the current script runs in app mode |

## Availability

- Since: `3.0.0`
- Radio support: `color-lcd`

`radio/src/lua/api_colorlcd_lvgl.cpp`
