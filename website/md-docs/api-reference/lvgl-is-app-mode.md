# lvgl.isAppMode

`lvgl.isAppMode()`

Test if widget is running in App Mode.

## Parameters

The function has no parameters.

## Returns

True if the widget is running in App Mode, false otherwise.

## Availability

- Since: `2.11.0`
- Radio support: `color-lcd`
