# lvgl.numberEdit

`lvgl.numberEdit([parent, ]params)`

Add a number edit box using the EdgeTX style.

## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `parent` | no | `object` | optional LVGL object to attach the new object to; if omitted the object is created in the top-level script window |
| `params` | yes | `table` | <ul><li>`x` (number) position relative to the top-left of the parent</li><li>`y` (number) position relative to the top-left of the parent</li><li>`w` (number) width</li><li>`h` (number) height</li><li>`color` (color or function) primary color for the object</li><li>`pos` (function) dynamic position callback returning `x, y`</li><li>`size` (function) dynamic size callback returning `w, h`</li><li>`visible` (function) dynamic visibility callback</li><li>`floating` (boolean) keep the object fixed inside a scrollable container, added in 2.11.6, defaults to false</li><li>`get` (function) called to get the current value to display, defaults to nil</li><li>`set` (function) called for every change to the number while editing; passed the new value, defaults to nil</li><li>`edited` (function) called after the user finishes editing; passed the final value (added in 2.11.5), defaults to nil</li><li>`active` (function) sets the enabled/disabled state; must return a boolean, true to enable, defaults to nil</li><li>`min` (number) minimum allowed value, defaults to -1024</li><li>`max` (number) maximum allowed value, defaults to 1024</li><li>`display` (function) overrides how the value is displayed; passed the current value, must return a string, defaults to nil</li></ul> |

## Returns

| Name | Type | Description |

| `-` | `table` | LVGL object, or nil if not running as a One-Time script or fullscreen widget |
