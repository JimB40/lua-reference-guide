# lvgl.textEdit

`lvgl.textEdit([parent, ]params)`

Add a text edit box using the EdgeTX style.

## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `parent` | no | `object` | optional LVGL object to attach the new object to; if omitted the object is created in the top-level script window |
| `params` | yes | `table` | <ul><li>`x` (number) position relative to the top-left of the parent</li><li>`y` (number) position relative to the top-left of the parent</li><li>`w` (number) width</li><li>`h` (number) height</li><li>`color` (color or function) primary color for the object</li><li>`pos` (function) dynamic position callback returning `x, y`</li><li>`size` (function) dynamic size callback returning `w, h`</li><li>`visible` (function) dynamic visibility callback</li><li>`floating` (boolean) keep the object fixed inside a scrollable container, added in 2.11.6, defaults to false</li><li>`value` (string or function) text to edit; if a function, the text can be changed by both script and user, defaults to an empty string</li><li>`length` (number) maximum editable text length, 1 to 128, defaults to 32</li><li>`set` (function) called when the user edits the text; passed the new string content, defaults to nil</li><li>`active` (function) sets the enabled/disabled state; must return a boolean, true to enable, defaults to nil</li></ul> |

## Returns
