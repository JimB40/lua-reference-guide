# lvgl.setting

`lvgl.setting([parent, ]params)`

Create a container for a single row of a settings page, automatically padded for controls such as toggle/textEdit/button.

## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `parent` | no | `object` | optional LVGL object to attach the new object to; if omitted the object is created in the top-level script window |
| `params` | yes | `table` | <ul><li>`x` (number) position relative to the top-left of the parent</li><li>`y` (number) position relative to the top-left of the parent</li><li>`w` (number) width</li><li>`h` (number) height</li><li>`color` (color or function) primary color for the object</li><li>`pos` (function) dynamic position callback returning `x, y`</li><li>`size` (function) dynamic size callback returning `w, h`</li><li>`visible` (function) dynamic visibility callback</li><li>`floating` (boolean) keep the object fixed inside a scrollable container, added in 2.11.6, defaults to false</li><li>`title` (string or function) text displayed on the left; function support added in 2.11.6, defaults to an empty string</li></ul> |

## Returns

| Name | Type | Description |
| --- | --- | --- |
| `-` | `table` | LVGL object, or nil if not running as a One-Time script or fullscreen widget |

## Availability

- Since: `2.11.0`
- Radio support: `color-lcd`
