# lvgl.font

`lvgl.font([parent, ]params)`

Display a button showing a font name. Tapping it opens a popup menu to choose a font from, using EdgeTX styling.

## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `parent` | no | `object` | optional LVGL object to attach the new object to; if omitted the object is created in the top-level script window |
| `params` | yes | `table` | <ul><li>`x` (number) position relative to the top-left of the parent</li><li>`y` (number) position relative to the top-left of the parent</li><li>`w` (number) width</li><li>`h` (number) height</li><li>`color` (color or function) primary color for the object</li><li>`pos` (function) dynamic position callback returning `x, y`</li><li>`size` (function) dynamic size callback returning `w, h`</li><li>`visible` (function) dynamic visibility callback</li><li>`floating` (boolean) keep the object fixed inside a scrollable container, added in 2.11.6, defaults to false</li><li>`get` (function) called on every refresh cycle to keep the displayed value in sync, to get the currently selected font, defaults to nil</li><li>`set` (function) called when the user taps a font in the popup; passed the selected font value, defaults to nil</li><li>`active` (function) sets the enabled/disabled state; must return a boolean, true to enable, defaults to nil</li></ul> |

## Returns

| Name | Type | Description |
| --- | --- | --- |
| `-` | `table` | LVGL object, or nil if not running as a One-Time script or fullscreen widget |

## Availability

- Since: `2.11.0`
- Radio support: `color-lcd`

## Notes

- Only available for One-Time scripts and widgets running in full screen mode -- returns nil otherwise.
  @notice The popup closes and `set` is called when the user selects an item.
  @notice If the user taps outside the popup or presses RTN, the popup closes without calling `set`.
