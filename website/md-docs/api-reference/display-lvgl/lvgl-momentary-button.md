# lvgl.momentaryButton

`lvgl.momentaryButton([parent, ]params)`

Add a momentary text button using the EdgeTX style.

## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `parent` | no | `object` | optional LVGL object to attach the new object to; if omitted the object is created in the top-level script window |
| `params` | yes | `table` | <ul><li>`x` (number) position relative to the top-left of the parent</li><li>`y` (number) position relative to the top-left of the parent</li><li>`w` (number) width</li><li>`h` (number) height</li><li>`color` (color or function) primary color for the object</li><li>`pos` (function) dynamic position callback returning `x, y`</li><li>`size` (function) dynamic size callback returning `w, h`</li><li>`visible` (function) dynamic visibility callback</li><li>`floating` (boolean) keep the object fixed inside a scrollable container, added in 2.11.6, defaults to false</li><li>`text` (string or function) text displayed in the button, defaults to an empty string</li><li>`press` (function) called immediately when the user first taps the button or presses ENTER, defaults to nil</li><li>`release` (function) called when the user releases ENTER or stops touching the screen, defaults to nil</li><li>`active` (function) sets the enabled/disabled state; must return a boolean, true to enable, defaults to nil</li><li>`color` (color or function) background color, defaults to the EdgeTX button style PRIMARY2 theme color</li><li>`textColor` (color or function) text color, defaults to the EdgeTX button style SECONDARY1 theme color</li><li>`cornerRadius` (number) radius for the button's corners, defaults to the EdgeTX button style radius</li><li>`font` (font value or function) sets the font size, e.g. `MIDSIZE`, `DBLSIZE`; defaults to `STDSIZE`</li></ul> |

## Returns

| Name | Type | Description |
| --- | --- | --- |
| `-` | `table` | LVGL object, or nil if not running as a One-Time script or fullscreen widget |

## Availability

- Since: `2.11.0`
- Radio support: `color-lcd`

## Notes

- Only available for One-Time scripts and widgets running in full screen mode -- returns nil otherwise.
  @notice Unlike `lvgl.button`, `press` fires immediately on tap/press rather than on release. The button shows the checked state until ENTER is released or the screen is no longer touched.
