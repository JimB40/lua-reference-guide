# lvgl.vline

`lvgl.vline([parent, ]params)`

Display a vertical line.

## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `parent` | no | `object` | optional LVGL object to attach the new object to; if omitted the object is created in the top-level script window |
| `params` | yes | `table` | <ul><li>`x` (number) position relative to the top-left of the parent</li><li>`y` (number) position relative to the top-left of the parent</li><li>`w` (number) width</li><li>`h` (number) height</li><li>`color` (color or function) primary color for the object</li><li>`pos` (function) dynamic position callback returning `x, y`</li><li>`size` (function) dynamic size callback returning `w, h`</li><li>`visible` (function) dynamic visibility callback</li><li>`floating` (boolean) keep the object fixed inside a scrollable container, added in 2.11.6, defaults to false</li><li>`rounded` (boolean) if true the line's end caps are rounded, defaults to false</li><li>`opacity` (number or function) opacity from 0 (transparent) to 255 (opaque), defaults to 255</li><li>`dashGap` (number) gap size for dashed lines, defaults to 0</li><li>`dashWidth` (number) dash size for dashed lines, defaults to 0; both `dashGap` and `dashWidth` must be > 0 to draw dashed lines</li></ul> |
