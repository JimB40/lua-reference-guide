# lvgl.box

`lvgl.box([parent, ]params)`

Create a container for managing object layout.

## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `parent` | no | `object` | optional LVGL object to attach the new object to; if omitted the object is created in the top-level script window |
| `params` | yes | `table` | <ul><li>`x` (number) position relative to the top-left of the parent</li><li>`y` (number) position relative to the top-left of the parent</li><li>`w` (number) width</li><li>`h` (number) height</li><li>`color` (color or function) primary color for the object</li><li>`pos` (function) dynamic position callback returning `x, y`</li><li>`size` (function) dynamic size callback returning `w, h`</li><li>`visible` (function) dynamic visibility callback</li><li>`floating` (boolean) keep the object fixed inside a scrollable container, added in 2.11.6, defaults to false</li><li>`flexFlow` (lvgl.FLOW_COLUMN or lvgl.FLOW_ROW) enables flex layout for this box, not used by default</li><li>`flexPad` (number) padding between rows/columns when flex layout is used; recommend using `lvgl.PAD_xxx` values, defaults to `PAD_OUTLINE`</li><li>`scrollBar` (boolean) enables/disables scroll bars, defaults to true</li><li>`scrollDir` (lvgl.SCROLL_xx) allowed scroll directions when child objects extend past the box bounds (stand alone scripts only), defaults to `lvgl.SCROLL_ALL`</li><li>`scrolled` (function) called when the box content is scrolled; passed `x`, `y` of the current scroll position, defaults to nil</li><li>`scrollTo` (function) overrides the box scroll position; must return `x`, `y` to scroll to, defaults to nil</li><li>`align` (alignment type (LEFT, RIGHT, CENTER, VTOP, VBOTTOM, VCENTER)) alignment used with flex layouts (added in 2.11.4); avoid combining an alignment with a scrollbar on the same axis, defaults to `CENTER | VTOP`</li><li>`borderPad` (number or table) border padding around the container edges; a single number applies to all sides, or a table `{left=?, right=?, top=?, bottom=?}` (added in 2.11.5), defaults to `PAD_OUTLINE` if `flexFlow` is set, otherwise 0</li></ul> |

## Availability

- Since: `2.11.0`
- Radio support: `color-lcd`

## Notes

- The box is a helper for managing screen layouts.
  @notice When adding controls such as button/toggle/textEdit, leave enough space around them for the focus outline.
  @notice In a stand alone tool script, the box automatically adds scroll bars if child objects fall outside its boundaries; for widgets, out-of-bounds children are clipped instead.
  @notice `scrollBar`, `scrollDir`, `scrolled`, and `scrollTo` were added in 2.11.2.
