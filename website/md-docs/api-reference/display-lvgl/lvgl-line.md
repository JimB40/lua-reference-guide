# lvgl.line

`lvgl.line([parent, ]params)`

Display one or more connected line segments.

## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `parent` | no | `object` | optional LVGL object to attach the new object to; if omitted the object is created in the top-level script window |
| `params` | yes | `table` | <ul><li>`x` (number) position relative to the top-left of the parent</li><li>`y` (number) position relative to the top-left of the parent</li><li>`w` (number) width</li><li>`h` (number) height</li><li>`color` (color or function) primary color for the object</li><li>`pos` (function) dynamic position callback returning `x, y`</li><li>`size` (function) dynamic size callback returning `w, h`</li><li>`visible` (function) dynamic visibility callback</li><li>`floating` (boolean) keep the object fixed inside a scrollable container, added in 2.11.6, defaults to false</li><li>`rounded` (boolean) if true the line's end caps are rounded, defaults to false</li><li>`thickness` (number) thickness of each line segment, defaults to 1</li><li>`opacity` (number or function) opacity from 0 (transparent) to 255 (opaque), defaults to 255</li><li>`pts` (table or function) table of points, each a `{x, y}` pair; at least two points are required, defaults to nil</li></ul> |
