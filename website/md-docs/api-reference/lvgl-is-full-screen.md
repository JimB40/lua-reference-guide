# lvgl.isFullScreen

`lvgl.isFullScreen()`

Return whether the current script is running in fullscreen mode.

## Parameters

None.

## Returns

| Name | Type | Description |
| --- | --- | --- |
| `-` | `boolean` | true when the current script runs in fullscreen mode |

## Availability

- Since: `3.0.0`
- Radio support: `color-lcd`
