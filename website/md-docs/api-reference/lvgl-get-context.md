# lvgl.getContext

`lvgl.getContext()`

Return the Lua context table associated with the current LVGL script, if any.

## Parameters

None.

| Name | Type | Description |
| --- | --- | --- |
| `-` | `table` | current LVGL context table |
| `-` | `nil` | no LVGL context is available |
