# lvgl.hide

`lvgl.hide(obj)`

Hide an LVGL object without destroying it.

## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `obj` | yes | `table` | LVGL object previously created by the `lvgl` library |

## Returns

None.

## Availability

- Since: `3.0.0`
- Radio support: `color-lcd`

`radio/src/lua/api_colorlcd_lvgl.cpp`
