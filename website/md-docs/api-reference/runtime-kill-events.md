# killEvents

`killEvents(key)`

Stop the key state machine.

## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `key` | yes | `integer` | key to be killed, can also include event type (only the key part is used) |

## Returns

None.

## Availability

- Since: `2.0.0`
- Radio support: `all`
