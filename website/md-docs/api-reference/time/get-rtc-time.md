# getRtcTime

`getRtcTime()`

Return current RTC system date as unix timstamp (in seconds since 1. Jan 1970)

## Parameters

None.

## Returns

| Name | Type | Description |
| --- | --- | --- |
| `-` | `integer` | Number of seconds elapsed since 1. Jan 1970 |

## Availability

- Since: `unknown`
- Radio support: `all`
