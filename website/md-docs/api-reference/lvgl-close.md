# lvgl.close

`lvgl.close(obj)`

Close an LVGL object that represents a closable container or dialog.

## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `obj` | yes | `table` | LVGL object previously created by the `lvgl` library |

## Returns

None.

## Availability

- Since: `3.0.0`
- Radio support: `color-lcd`
