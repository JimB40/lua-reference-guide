    Model Functions

    Model data access and editing APIs.

    Curves

    model.getCurve Get Curve parameters model.setCurve Set Curve parameters

    Flight Modes

    getFlightMode Return the current flight mode number and name. model.deleteFlightModes Clear all flightModes model.getFlightMode Needs summary review model.setFlightMode Set Flight mode parameters

    Global Variables

    model.getGlobalVariable Return current global variable value model.setGlobalVariable Set the current global variable value.

    Heli

    model.getSwashRing Get heli swash parameters model.setSwashRing Set heli swash parameters

    Inputs

    model.defaultInputs Set all inputs to defaults model.deleteInput Delete line from specified input model.deleteInputs Delete all Inputs model.getInput Return input data for given input and line number model.getInputsCount Return number of lines for given input model.insertInput Insert an Input at specified line

    Logical Switches

    model.getLogicalSwitch Get Logical Switch parameters model.setLogicalSwitch Set Logical Switch parameters

    Mixes

    model.deleteMix Delete mixer line from specified Channel model.deleteMixes Remove all mixers model.getMix Get configuration for specified Mix model.getMixesCount Get the number of Mixer lines that the specified Channel has model.insertMix Insert a mixer line into Channel

    Model Setup

    model.getInfo Get current Model information model.setInfo Set the current Model information model.getSwitchWarning Get warning state for a switch model.setSwitchWarning Set warning state for a switch

    Outputs

    getOutputValue Return the current value of an output channel. model.getOutput Get servo parameters model.setOutput Set servo parameters

    RF Modules

    model.getModule Get RF module parameters model.setModule Set RF module parameters

    Special Functions

    model.getCustomFunction Get Custom Function parameters model.setCustomFunction Set Custom Function parameters

    Telemetry Sensors

    model.getSensor Get Telemetry Sensor parameters model.resetSensor Reset Telemetry Sensor parameters

    Timers

    model.getTimer Get model timer parameters model.setTimer Set model timer parameters model.resetTimer Reset model timer to a startup value
